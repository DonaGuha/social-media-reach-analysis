# Social Media Reach Analysis Dashboard

## Project Overview

This project analyzes social media performance across
Instagram, Facebook and YouTube.

It provides an interactive dashboard to understand
audience reach, impressions, engagement and follower growth.

## Objectives

- Analyze social media reach.
- Compare different social media platforms.
- Study likes, comments and shares.
- Analyze audience engagement.
- Identify the best-performing post types.
- Track follower growth.
- Visualize social media performance.

## Technologies Used

- Python
- Pandas
- Streamlit
- Plotly
- CSV

## Project Features

1. Interactive dashboard.
2. Platform-wise performance analysis.
3. Reach and impressions visualization.
4. Engagement analysis.
5. Post type comparison.
6. Audience growth analysis.
7. Interactive filters.
8. Dataset download option.
9. Automatic performance insights.

## Installation

Clone the repository:

git clone https://github.com/YOUR_USERNAME/social-media-reach-analysis.git

Navigate to the project folder:

cd social-media-reach-analysis

Install dependencies:

pip install -r requirements.txt

Run the application:

python -m streamlit run app.py
